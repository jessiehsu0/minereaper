# OOP Design Patterns
The Builder, Factory, and Strategy Pattern are currently in place right now. 
There is a Tile Factory class that is responsible for building the tiles within the grid, 
and this is used in conjunction with the GridBuilder to construct the grids for the minereaper game (we may
expand to more complicated grids eventually so the builder pattern is especially useful there).
The Strategy Pattern is being used for the power ups - it'll come in handy once we add in more variations
of power ups into the game.
